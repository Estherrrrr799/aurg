# aurg · 独立轻量版

这是 aurg 脱离 muse.ai 之后的独立版本：一个单文件静态网页，不用账号，不用服务器，别人打开链接就能用自己的句库。

## 功能（对齐原 v2）

- **今日重逢**：每天最多推 5 句，优先推少见的句子，全库轮换。当天第一次打开时生成当日牌组，之后当天不再变；新存的句子从第二天开始进入轮换。
- **存句**：英文必填，译文 / 出处 / 备注可选，可选已有分类或顺手新建分类。
- **句库**：关键词搜索、按分类筛选，每句可编辑 / 改分类 / 删除；分类可新建 / 改名 / 删除，删分类不删句子。
- **备份**：句库底部可导出 JSON 备份，也可导入合并（同 ID 不重复）。

## 数据存在哪里

只存在每个使用者自己的浏览器 `localStorage` 里（键名 `aurg-standalone-v1`）。

- 优点：不用注册、不用服务器、别人的句子互不可见。
- 代价：换浏览器、换设备就看不到原来的句子；清浏览器数据也会丢。所以要定期用页面里的“导出备份”保存。

句库从空开始，不含原静态版的 48 句。

## 放到 GitHub Pages（免费）

1. 在 GitHub 新建一个仓库，例如 `aurg`（Public 即可，别人才能打开 Pages 链接）。
2. 把本目录的 `index.html` 上传到仓库根目录（`README.md` 可传可不传，不影响运行）。
3. 仓库 Settings → Pages → Build and deployment → Source 选择 **Deploy from a branch**，Branch 选择 `main`、文件夹 `/ (root)`，保存。
4. 等一两分钟，Pages 会给出一个 `https://<你的用户名>.github.io/aurg/` 这样的链接，别人打开就能用。

本地直接双击 `index.html` 也能打开使用，效果一样，只是没有线上链接。

## 之后可以走的方向（暂不做）

- 手机浏览器版：同一页面做响应式适配 + “添加到主屏幕”，不用重写。
- 浏览器插件：刷视频时一键存句。
- 微信小程序：需另外注册与开发，不由本网页直接转换。
- 跨设备同步：需加后端与账号，不再是轻量版。
